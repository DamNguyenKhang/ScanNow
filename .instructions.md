# ScanNow Project Instructions

File nay la guideline bat buoc cho AI/dev khi code trong du an ScanNow. Muc tieu la moi chuc nang moi deu di theo cung mot flow, cung cau truc thu muc, de code dong bo, de review va de bao tri.

## 1. Kien Truc Tong Quan

Du an theo mo hinh 4 layer:

- `ScanNow.Domain`: Entity, Enum, Domain Exception, Abstraction cho persistence/external service.
- `ScanNow.Application`: DTO, Validator, Mapper, Interface service, Service xu ly business logic.
- `ScanNow.Infrastructure`: DbContext, Entity Configuration, Repository implementation, external service implementation, seed data.
- `ScanNow.Web`: Controller, middleware, exception handler, DI presentation.

Quy tac quan trong:

- Controller khong chua business logic.
- Service xu ly nghiep vu, validation ve quyen/scope, goi repository/unit of work.
- Repository chi xu ly truy van/persistence, khong chua rule nghiep vu.
- Domain khong phu thuoc Application, Infrastructure, Web.
- Application khong viet truc tiep `HttpContext`; dung `ICurrentUserService`.
- Response thanh cong dung `ApiResponse<T>`.
- Loi nem exception trong service, de exception handler map sang `ProblemDetails`.

## 2. Flow Code Cho Mot Chuc Nang Moi

Khi them mot feature, AI/dev phai di theo checklist nay theo thu tu:

1. Domain
   - Them `Entity` neu co bang/database model moi.
   - Them `Enum` neu co tap gia tri dung chung.
   - Them custom exception neu loi co y nghia nghiep vu rieng.
   - Them interface repository vao `ScanNow.Domain/Abstractions/Persistence` neu can query dac thu.

2. Infrastructure
   - Them `IEntityTypeConfiguration<T>` trong `ScanNow.Infrastructure/Configurations`.
   - Them `DbSet<T>` vao `ApplicationDbContext` neu co entity moi.
   - Implement repository trong `ScanNow.Infrastructure/Repositories`.
   - Dang ky repository trong `ScanNow.Infrastructure/DependencyInjection.cs`.
   - Them seed trong `ScanNow.Infrastructure/Data` neu feature can du lieu mac dinh.
   - Tao migration neu co thay doi schema.

3. Application
   - Tao DTO request/response/query trong `ScanNow.Application/Features/{Feature}/DTOs`.
   - Tao validator trong `ScanNow.Application/Features/{Feature}/Validators`.
   - Tao mapper trong `ScanNow.Application/Mappers` hoac folder mapper cua feature neu project dang dung pattern do.
   - Tao service interface trong `ScanNow.Application/Abstractions`.
   - Tao service implementation trong `ScanNow.Application/Features/{Feature}`.
   - Dang ky service trong `ScanNow.Application/DependencyInjection.cs`.
   - Service phai async/await va khong return entity truc tiep ra Web.

4. Web
   - Tao controller trong `ScanNow.Web/Controllers`.
   - Controller chi nhan request, goi service, tra `ApiResponse<T>`.
   - Dung `[Authorize]` va `[Authorize(Roles = "...")]` neu endpoint can login/role.
   - Khong query DbContext/UserManager truc tiep trong controller neu logic thuoc use-case.

5. Verification
   - Chay `dotnet build`.
   - Neu co test thi chay test lien quan.
   - Neu thay doi database thi tao migration va build lai.

## 4. Repository Pattern

Dung repository khi:

- Query phuc tap, dung nhieu noi, hoac can dong goi persistence.
- Can gom cac truy van theo aggregate/feature.
- Can tach service khoi EF query chi tiet.

Interface repository dat trong Domain:

```csharp
public interface IUserManagementRepository
{
    Task<ApplicationUser?> GetUserWithScopeAsync(Guid userId, CancellationToken ct = default);
    Task<bool> EmailExistsAsync(string email, Guid? excludeUserId = null, CancellationToken ct = default);
}
```

Implementation dat trong Infrastructure:

```csharp
public class UserManagementRepository : IUserManagementRepository
{
    private readonly ApplicationDbContext _context;

    public UserManagementRepository(ApplicationDbContext context)
    {
        _context = context;
    }
}
```

Quy tac:

- Repository method phai async neu cham database.
- Repository khong throw `ForbiddenException` cho business ownership; viec do nam trong service.
- Repository khong map sang response DTO tru khi project da quy uoc ro.
- Khong dung raw SQL neu EF Core lam duoc ro rang.

## 5. DTO

DTO nam trong Application, khong nam trong Web.

Dat ten:

- `Create{Entity}Request`
- `Update{Entity}Request`
- `{Entity}Response`
- `{Entity}ListItemResponse`
- `{Entity}Query`
- `PagedResult<T>` hoac dung page response co san cua project.

Quy tac:

- Request DTO chi chua input tu client.
- Response DTO chi chua data can tra ve.
- Khong return `ApplicationUser`, `Restaurant`, `Branch` truc tiep tu API.
- Query params nen gom vao class query neu endpoint co nhieu filter/sort/page.

## 6. Validation

Dung FluentValidation cho input validation.

Validator dat trong:

```text
ScanNow.Application/Features/{Feature}/Validators
```

Vi du:

```csharp
public class CreateOwnerRequestValidator : AbstractValidator<CreateOwnerRequest>
{
    public CreateOwnerRequestValidator()
    {
        RuleFor(x => x.FullName).NotEmpty().MaximumLength(150);
        RuleFor(x => x.Email).NotEmpty().EmailAddress().MaximumLength(256);
        RuleFor(x => x.Password).NotEmpty().MinimumLength(6);
    }
}
```

Quy tac:

- Validator xu ly format, required, length, range, enum string hop le.
- Service xu ly validation can database: email trung, user co ton tai, branch co thuoc owner khong.
- Loi validation nen throw `ValidationException` hoac de FluentValidation middleware/filter cua project xu ly neu da co.

## 7. Mapper

Dung mapper de chuyen Entity sang DTO.

Neu project dang dung AutoMapper:

- Tao profile trong `ScanNow.Application/Mappers`.
- Dang ky da co qua `AddAutoMapper`.

Neu mapping co dieu kien phuc tap/scope:

- Co the dung static mapper/helper trong Application.
- Khong map trong controller.

Quy tac:

- Mapping don gian: AutoMapper.
- Mapping can role/scope/grouping/aggregate: service build response hoac dung mapper rieng.
- Khong de EF entity leak ra API response.

## 8. Service Interface Va Service

Interface dat trong:

```text
ScanNow.Application/Abstractions
```

Implementation dat trong:

```text
ScanNow.Application/Features/{Feature}
```

Vi du:

```csharp
public interface IUserManagementService
{
    Task<PagedResult<UserResponse>> GetUsersAsync(UserQuery query);
    Task<UserResponse> CreateUserAsync(CreateUserRequest request);
    Task<UserResponse> UpdateUserAsync(Guid id, UpdateUserRequest request);
}
```

Service rules:

- Moi method async phai co suffix `Async`.
- Lay current user qua `ICurrentUserService`.
- Kiem tra permission/scope trong service.
- Goi repository/UserManager/RoleManager/UnitOfWork tuy theo feature.
- Throw exception dung loai.
- Khong return `IQueryable` ra ngoai service.
- Khong dat business logic trong controller.

## 9. Controller

Controller dat trong:

```text
ScanNow.Web/Controllers
```

Controller chi lam cac viec:

- Nhan route/body/query.
- Goi service.
- Tra `ApiResponse<T>`.
- Gan attribute authorization.

Vi du:

```csharp
[ApiController]
[Route("api/admin/users")]
[Authorize(Roles = "SYSTEM_ADMIN")]
public class AdminUsersController : ControllerBase
{
    private readonly IUserManagementService _service;

    public AdminUsersController(IUserManagementService service)
    {
        _service = service;
    }

    [HttpGet("owners")]
    public async Task<ActionResult<ApiResponse<PagedResult<OwnerResponse>>>> GetOwners([FromQuery] OwnerQuery query)
    {
        return new ApiResponse<PagedResult<OwnerResponse>>
        {
            Result = await _service.GetOwnersAsync(query),
            Message = "Get owners successfully"
        };
    }
}
```

Khong duoc:

- Inject `ApplicationDbContext` vao controller de query business data.
- Viet if/else ownership phuc tap trong controller.
- Return entity truc tiep.

## 10. Exception

Dung exception co san:

- `ValidationException`: input sai, enum invalid, page/sort invalid.
- `BusinessRuleException`: vi pham rule nghiep vu, vi du owner chua co restaurant.
- `NotFoundException`: resource khong ton tai.
- `ConflictException`: email/slug/code bi trung.
- `UnauthorizedException`: chua login/token invalid.
- `ForbiddenException`: co login nhung khong co quyen/sai scope.

Rule:

- Service throw exception.
- Controller khong try/catch neu exception handler da xu ly.
- Message loi nen ro, ngan gon, dung tieng Anh hoac style dang co trong project.

## 11. Authorization Va Scope

Dung role constants/enum neu co. Ten role phai dong bo voi Identity role trong database va JWT.

Role hien tai nen dung:

- `ADMIN`
- `OWNER`
- `BRANCH_MANAGER`
- `STAFF`
- `KITCHEN`

Quy tac:

- `[Authorize]` de chan user chua login.
- `[Authorize(Roles = "...")]` de chan sai role o controller.
- Service van phai check ownership/scope.
- Khong role nao duoc thao tac data ngoai nha hang/chi nhanh cua minh.

## 12. Pagination, Search, Sort

Query DTO nen co:

```csharp
public int PageNumber { get; set; } = 1;
public int PageSize { get; set; } = 10;
public string? Search { get; set; }
public string? SortBy { get; set; }
public string? SortDirection { get; set; } = "asc";
```

Quy tac:

- `PageNumber` mac dinh `1`.
- `PageSize` mac dinh `10`.
- `PageSize` toi da `100`.
- `SortDirection` chi nhan `asc` hoac `desc`.
- Search nen trim va check empty.
- Sort field phai whitelist, khong sort dynamic tuy tien tu client.

## 13. Unit Of Work

Dung `IUnitOfWork.SaveChangesAsync()` khi:

- Repository chi add/update/delete entity.
- Mot use-case thay doi nhieu bang can commit cung luc.

Neu dung `UserManager`/`RoleManager`:

- Cac method Identity thuong tu save thay doi cua Identity.
- Neu cung luc thay doi entity khac bang DbContext, van can `IUnitOfWork.SaveChangesAsync()`.

## 14. Database Migration

Can migration khi:

- Them/sua/xoa entity/table/column/index/relation.
- Sua EF configuration lam thay doi schema.

Lenh:

```bash
dotnet ef migrations add <MigrationName> -p ScanNow.Infrastructure -s ScanNow.Web
dotnet ef database update -p ScanNow.Infrastructure -s ScanNow.Web
```

Khong can migration khi:

- Chi them service/controller/DTO/validator.
- Chi them seed logic ma khong doi schema.

## 15. Dependency Injection

Application service dang ky trong:

```text
ScanNow.Application/DependencyInjection.cs
```

Infrastructure repository/external service dang ky trong:

```text
ScanNow.Infrastructure/DependencyInjection.cs
```

Quy tac:

- Interface -> implementation phai duoc dang ky.
- Dung `AddScoped` cho service/repository lam viec voi DbContext.
- Khong dang ky service Application trong Web neu project da co extension `AddApplication`.

## 16. Build Va Review Checklist

Truoc khi ket thuc task, AI/dev phai tu check:

- Da dung dung layer chua?
- Controller co mong khong?
- Service co check quyen/scope khong?
- Co DTO request/response rieng khong?
- Co validation cho input chua?
- Co mapper neu mapping lap lai/phuc tap khong?
- Co repository neu query/persistence phuc tap khong?
- Co exception dung loai khong?
- Co dang ky DI chua?
- Co migration neu doi schema chua?
- `dotnet build` co thanh cong khong?

## 17. Quy Tac Code Style

- Ten class/method/property dung PascalCase.
- Interface bat dau bang `I`.
- Method async ket thuc bang `Async`.
- Khong viet comment thua cho code tu giai thich duoc.
- Khong hard-code role/string lap lai nhieu noi neu co enum/constant.
- Khong xoa/sua code ngoai scope task neu khong can thiet.
- Neu worktree co thay doi san, khong revert thay doi cua nguoi khac.

## 18. Template Nhanh Cho Mot CRUD Feature

Khi user yeu cau tao feature CRUD, hay tao toi thieu:

- `Entity` neu can bang moi.
- `I{Feature}Repository`.
- `{Feature}Repository`.
- `Create{Feature}Request`.
- `Update{Feature}Request`.
- `{Feature}Response`.
- `{Feature}Query` neu co list/search/sort/page.
- `{Feature}Validator`.
- `{Feature}Mapper` hoac AutoMapper profile.
- `I{Feature}Service`.
- `{Feature}Service`.
- `{Feature}Controller`.
- DI registration.
- Migration neu doi schema.
- Build verification.

Neu feature khong can mot thanh phan nao, phai co ly do ro rang. Vi du: khong tao repository rieng neu query rat don gian va project hien tai chua dung repository cho aggregate do.
